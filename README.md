# NETWORKWALKS-B083-WK3-PASSWORD-CRACKING-LABS

## Week 3 - Password Cracking Labs

This repository contains my Week 3 project work for the NetworkWalks Cybersecurity & Ethical Hacking program.

## Project Modules

### W3-PM1 - Password Cracking with JTR

In this module, I worked with John the Ripper (JTR) and Johnny to recover the password of the protected PDF used in the lab.

The process covered:

1. Installing John the Ripper and Johnny.
2. Configuring Johnny to use `john.exe`.
3. Extracting the PDF hash.
4. Saving the hash in a text file.
5. Loading the hash into Johnny.
6. Starting the password recovery attack.
7. Using the recovered password to open the PDF.

The supplied lab solution shows the recovered password as `password1`.

### W3-PM2 - Password Cracking with NetworkWalks Tools

In this module, I used the NetworkWalks Hash Calculator and Password Cracker to recover the password of the protected PDF.

The process covered:

1. Uploading the protected PDF to the Hash Calculator.
2. Extracting the `$pdf$...` hash.
3. Copying the complete hash.
4. Pasting the hash into the Password Cracker.
5. Starting the password recovery process.
6. Using the recovered password to open the PDF.

The supplied lab solution shows the recovered password as `password1`.
